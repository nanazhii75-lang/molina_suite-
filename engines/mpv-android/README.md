# Molina mpv (engine)

Pemutar video untuk molina-suite (`com.molina.suite.mpv`). Source ini adalah turunan dari
mpv-android, tag 2024-11-16: https://github.com/mpv-android/mpv-android
Pemutaran memakai [libmpv](https://github.com/mpv-player/mpv).

- Lisensi: [LICENSE](LICENSE), tidak diubah. Header lisensi dan nama author asli di berkas
  sumber dipertahankan.
- Atribusi seluruh proyek: [../../docs/ATTRIBUTION.md](../../docs/ATTRIBUTION.md)

## Catatan

- Aplikasi dibangun oleh monorepo molina-suite (lihat root repositori), bukan dari folder ini.
- Pustaka native (libmpv, FFmpeg, dan lainnya) dibangun oleh skrip di [buildscripts](buildscripts/README.md).
- Mesin ini bukan library (AAR) yang bisa diimpor ke aplikasi lain.
